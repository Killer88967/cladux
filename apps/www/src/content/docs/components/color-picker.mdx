## Usage

```tsx
import {
  ColorPicker,
  ColorPickerAlpha,
  ColorPickerArea,
  ColorPickerEyeDropper,
  ColorPickerHue,
  ColorPickerInput,
} from "@cladux/ui";
```

```tsx
<ColorPicker defaultValue="#6366f1">
  <ColorPickerArea />
  <ColorPickerHue />
  <ColorPickerAlpha />
  <ColorPickerInput />
</ColorPicker>
```

## Composition

```text
ColorPicker
├── ColorPickerArea
├── ColorPickerHue
├── ColorPickerAlpha
├── ColorPickerSwatches
├── ColorPickerEyeDropper
└── ColorPickerInput
```

Use only the parts you need. Every part is optional, and the order is up to you.

## Features

- **It has no dependencies.** The color math is about 50 lines and is exported: `hexToHsva`, `hsvaToHex` and `hsvaToRgba`.
- **It keeps hue through grey.** Dragging to black or white and back keeps the hue you had, instead of jumping to red.
- **It speaks hex.** `value` is `#rrggbb`, or `#rrggbbaa` when the opacity is below 100%. It also accepts `#rgb`.
- **It uses the eye dropper where the browser has one.** `ColorPickerEyeDropper` renders nothing in browsers without the EyeDropper API.

## Custom Parts

`useColorPicker()` returns `hsva`, `hex`, `update(patch)` and `setHex(hex)`, for building your own parts inside `ColorPicker`.

```tsx
function Lightness() {
  const { hsva, update } = useColorPicker()
  return <button onClick={() => update({ v: 1 })}>Brightest</button>
}
```

## Accessibility

The area, hue and opacity are sliders that you can focus. The arrow keys move by 1%, or by 10% with `Shift`. The area uses left and right for saturation and up and down for brightness. The hex field applies a full color as you type and puts the last value back on `Escape`.

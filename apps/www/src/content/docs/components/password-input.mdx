## Usage

```tsx
import { PasswordInput, PasswordStrength } from "@cladux/ui";
```

```tsx
const [password, setPassword] = React.useState("")

<PasswordInput value={password} onChange={(e) => setPassword(e.target.value)} />
<PasswordStrength value={password} />
```

## Strength

`PasswordStrength` scores the password from 0 to 4 and lists which rules pass. It is a separate component, so a sign-in form can use `PasswordInput` alone.

<ComponentPreview name="password-input-strength" />

For a sign-up form, set `autoComplete="new-password"` so password managers offer to generate one.

## Custom Rules

Pass your own `rules`. Each rule has a `label` and a `test`. The score is the share of rules that pass.

<ComponentPreview name="password-input-rules" />

```tsx
const rules: PasswordRule[] = [
  { label: "At least 12 characters", test: (p) => p.length >= 12 },
  { label: "No spaces", test: (p) => p.length > 0 && !/\s/.test(p) },
];
```

To hide the list and show only the meter, set `showRules={false}`. To score a password yourself, call `getPasswordStrength(password, rules)`.

> The rules check the shape of a password, not whether it has leaked. For that, check it on the server against a list such as Have I Been Pwned.

## API Reference

### PasswordInput

Takes every `input` prop except `type`. The toggle switches the type between `password` and `text`.

### PasswordStrength

| Prop        | Type             | Default                |
| ----------- | ---------------- | ---------------------- |
| `value`     | `string`         |                        |
| `rules`     | `PasswordRule[]` | `defaultPasswordRules` |
| `showRules` | `boolean`        | `true`                 |

## Accessibility

The toggle is a button with `aria-pressed` and a label that says what it will do. The strength label is announced politely as it changes, and each rule says whether it is met.

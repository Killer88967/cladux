```tsx

```

## Features

- **It confirms.** The icon turns into a check for two seconds, and screen readers hear "Copied".
- **It copies what's current.** Pass a function to `value` to work out the text at the moment of the click.
- **It works without HTTPS.** Outside a secure context, where the Clipboard API is missing, it falls back to `execCommand("copy")`.
- **It is a Button.** It takes every `variant` and `size` that [Button](/docs/components/button) does.

## Hook

`useCopyToClipboard()` gives you the same behavior for your own UI.

```tsx
const { copied, copy } = useCopyToClipboard({ timeout: 2000 })

<button onClick={() => copy(url)}>{copied ? "Copied!" : "Share"}</button>
```

`copy` returns `true` when the text was copied.

## API Reference

`CopyButton` takes every `Button` prop, plus:

| Prop          | Type                      | Default     |
| ------------- | ------------------------- | ----------- |
| `value`       | `string \| () => string`  |             |
| `onCopy`      | `(value: string) => void` |             |
| `timeout`     | `number`                  | `2000`      |
| `label`       | `string`                  | `"Copy"`    |
| `copiedLabel` | `string`                  | `"Copied"`  |
| `variant`     | Button variant            | `"ghost"`   |
| `size`        | Button size               | `"icon-sm"` |

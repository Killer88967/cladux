## Usage

```tsx
import { ContributionGraph } from "@cladux/ui";
```

```tsx
<ContributionGraph
  data={[
    { date: "2026-03-04", count: 12 },
    { date: "2026-03-05", count: 3 },
  ]}
/>
```

## Features

- **It follows your theme.** Days are drawn in your primary color, in five levels from empty to busiest, and switch with dark mode.
- **Levels fit your data.** By default, each level is a quarter of your busiest day. Pass `thresholds` to choose them yourself.
- **Dates are days, not instants.** `"2026-03-04"` means March 4 wherever the page is viewed, not the evening of March 3 in the Americas. Several entries for the same day add up.
- **It fits small screens.** When the year is wider than its box, it scrolls sideways and starts on the newest days.
- **One tab stop.** Tab reaches the graph once, the arrow keys move between days and weeks, and each day reads its count aloud.

## Clickable days

Pass `onDayClick` and the days become buttons. `formatDay` changes the words in the tooltip, and `summary` the line underneath.

<ComponentPreview name="contribution-graph-interactive" clientOnly />

```tsx
<ContributionGraph
  data={commits}
  thresholds={[1, 3, 6, 10]}
  formatDay={(day, date) => `${day.count} commits on ${date}`}
  summary={(total) => `${total} commits in the last year`}
  onDayClick={(day) => setSelected(day)}
/>
```

## A calendar year

Set `start` and `end` for any range, such as a whole year. `weekStart={1}` starts weeks on Monday.

<ComponentPreview name="contribution-graph-year" />

```tsx
<ContributionGraph
  data={data}
  start={new Date(2025, 0, 1)}
  end={new Date(2025, 11, 31)}
  weekStart={1}
  summary={(total) => `${total} contributions in 2025`}
/>
```

## Other languages

Month and day names come from `Intl`, in the browser's language, or the one you pass to `locale`. Give `formatDay` and `summary` your own words to go with them.

```tsx
<ContributionGraph
  data={data}
  locale="fr-FR"
  weekStart={1}
  formatDay={(day, date) => `${day.count} contributions le ${date}`}
  summary={(total) => `${total} contributions cette année`}
/>
```

## Rendering on the server

Without `end`, the graph ends today, and today on the server can be a different day from today in the browser. When the page is rendered ahead of time, pass `end`, or render the graph in the browser only.

## Styling

Each day has `data-level`, from `0` to `4`, so you can recolor the levels with CSS:

```css
[data-slot="contribution-graph-day"][data-level="4"] {
  background: #216e39;
}
```

The size of the squares comes from the `--cell` variable, `0.75rem` by default:

```tsx
<ContributionGraph data={data} style={{ "--cell": "1rem" } as React.CSSProperties} />
```

## API Reference

### ContributionGraph

| Prop         | Type                                                  | Default                 |
| ------------ | ----------------------------------------------------- | ----------------------- |
| `data`       | `{ date: Date \| string; count: number }[]`           |                         |
| `end`        | `Date`                                                | today                   |
| `start`      | `Date`                                                | a year before `end`     |
| `thresholds` | `[number, number, number, number]`                    | quarters of the busiest |
| `weekStart`  | `0 \| 1`                                              | `0` (Sunday)            |
| `locale`     | `string`                                              | the browser's           |
| `formatDay`  | `(day: ContributionGraphDay, date: string) => string` | "12 contributions on…"  |
| `summary`    | `((total: number) => ReactNode) \| false`             | "1,234 contributions…"  |
| `legend`     | `boolean`                                             | `true`                  |
| `onDayClick` | `(day: ContributionGraphDay) => void`                 |                         |

### ContributionGraphDay

| Field   | Type     | What it is                       |
| ------- | -------- | -------------------------------- |
| `date`  | `Date`   | Midnight, local time, of the day |
| `count` | `number` | The day's total                  |
| `level` | `number` | `0` (none) to `4` (busiest)      |

## Accessibility

The graph is a single tab stop. From there, the up and down arrows move a day, left and right move a week (mirrored in right-to-left layouts), and Home and End jump to the first and last day. Each day has a label with its count and full date, and the same words show in the tooltip on hover and focus. Without `onDayClick`, days are images; with it, they're buttons.

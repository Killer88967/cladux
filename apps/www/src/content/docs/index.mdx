Cladux is a set of accessible React components you copy into your project with a CLI, and own from then on. Every component looks the same with or without Tailwind: projects with Tailwind v4 get Tailwind classes, projects without it get plain CSS files.

## What's included

- **Components**: 60+ React components built on Radix, from buttons to sidebars, charts and data tables.
- **Two styles**: Tailwind v4 classes, or a CSS file per component. The CLI picks the one that fits your project.
- **CSS-only components**: `cl-*` classes and a tiny script for sites without React.
- **Tokens**: colors and radius as CSS variables you can theme.

## Get started

Run `init` in your project, then add what you need:

<CliCommand args="init" />

<CliCommand args="add button" />

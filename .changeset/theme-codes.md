Theme codes. Pick a theme on https://cladux.vercel.app/themes and apply its code with `cladux apply zinc-violet`, or start with one: `cladux init --theme zinc-violet`. The code is saved in `cl.json`. `cladux-registry` reads theme codes and turns them into CSS, with a browser-safe `cladux-registry/theme` entry.
